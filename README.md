# Number Adder

Helps you to perform simple arithmetic operation.

## User

Anyone faced with the task of adding numbers

## Problem

Pressing the calculator to add large numbers seems tedious, number adder helps you save time and effort in achieving this task

## How to use

Enter the numbers you want to add, each separated by a comma "," then press the add button to display result

## Checks that prove number adder works

- It skips input that are not numbers
- It display correct result on the interface
- It trims white space at the begining or ending of a number to ensure accurate result

## Limitations

- Number adder won't display or log error of incorrect input
- Number adder won't give result to a specific decimal place, result depends on the input given
